**Renamed the add-on from `8Crafter's Debug Sticks, Chat Ranks, Custom UI, JavaScript Commands/Script REPL, and Server Utilities` to `8Crafter's Server Utilities & Debug Sticks`!**

## Additions

### Commands

-   Added the [`\\loadchunks`{lang=acmd}](../commands-list/--loadchunks) command. It has one alias: `\\lc`{lang=acmd}.
-   Added the `duration` parameter to the [`\selectionrender`{lang=acmd}](../commands-list/-selectionrender) command.
-   Added the `t` flag to the [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command. This flag causes the command to create ghost items if the slot type is a number or `~`.

### Settings

-   Added the [`Default Min MS Between Tick Waits`](../settings/script#default-min-ms-between-tick-waits) setting [`config.system.defaultMinMsBetweenTickWaits`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.system.html#defaultminmsbetweentickwaits) to the [Script Settings](../settings/script) menu.
-   Added 4 new options related to the console and chat logs about whether or not a compatible version of the [BlueMods Anticheat](/../main/add-ons/bluemods-anticheat) add-on is on the world to the [Script Settings](../settings/script) menu.

## Changes

### Commands

-   The [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command now no longer creates ghost items, unless the new `t` flag is used and the slot type is a number or `~`.
-   The [`\takeitem`{lang=acmd}](../commands-list/-takeitem) command now takes a target selector instead of a player name.
-   The [`\copyitem`{lang=acmd}](../commands-list/-copyitem) command now takes a target selector instead of a player name.
-   The [`\copyitem`{lang=acmd}](../commands-list/-copyitem) command now allows for multiple targets.

### Settings

-   Massive overhaul to the [Script Settings](../settings/script) menu.

## Removals

### Settings

-   Removed the [`Protected Areas Refresh Rate`](../settings/script#protected-areas-refresh-rate) option from the [Script Settings](../settings/script) menu.

## Fixes

### Commands

-   Fixed the [`\swapitems`{lang=acmd}](../commands-list/-swapitems) command.
-   Fixed the [`\copyitemfrom`{lang=acmd}](../commands-list/-copyitemfrom) command.

### Entities

-   Fixed a bug where the [`andexdb:tickingarea_6`{lang=mccmd}](../entities/tickingarea_6) entity could not be made visible if [Entity Scale](/../main/add-ons/entity-scale) was not on the world.

### UIs

-   Fixed a bug where the Manage Bans menu used [`config.ui.pages.maxPlayersPerManagePlayersPage`](../settings/ui#max-players-per-manage-players-page) instead of [`config.ui.pages.maxBansPerManageBansPage`](../settings/ui#max-bans-per-manage-bans-page) for the number of entries per page.
-   Fixed a bug where the Bounties Placed By Me menu still used the old UI style.
-   Fixed a bug where the Individual Bounties menu still used the old UI style.
-   Fixed a bug where the Home Details menu still used the old UI style.
-   Fixed a bug where the New Home menu still used the old UI style.
-   Fixed a bug where the Place Bounty menu threw an error when the player had already placed a bounty on the target, now it shows a warning instead, saying that to do it, they will have to remove the previous bounty first, and it provides and option to do so.
-   Fixed a bug where the icon for the View Individual Bounties button was an arrow pointing left instead of right.
-   Fixed bugs with the player and server shop systems where some of the menus had not yet been updated to the new UI style.

## Technical Additions

### API

#### cmdutils Module

-   Added [`modules.cmdutils.getItemFromParsedSlot`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/functions/Globals.modules.cmdutils.getItemFromParsedSlot.html)

#### Config

-   Added [`config.system.defaultMinMSBetweenTickWaits`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.system.html#defaultminmsbetweentickwaits).

## Technical Changes

-   When Entity Scale or BlueMods Anticheat are not detected upon startup, the add-on will now tell you in the console as a warning, rather than a log, so that you don't have to change your log level to see it.

### API

#### cmdutils Module

-   Massive performance improvements to the [`modules.cmdutils.getSlotFromParsedSlot`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/functions/Globals.modules.cmdutils.getSlotFromParsedSlot.html) function.
-   Massive performance improvements to the [`modules.cmdutils.parseSlot`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/functions/Globals.modules.cmdutils.parseSlot.html) function.

#### Config

-   Deprecated [`config.system.protectedAreasRefreshRate`{lang=ts}](https://api.8crafter.com/andexdb/v1.35.0/classes/Globals.config.system.html#protectedareasrefreshrate).
